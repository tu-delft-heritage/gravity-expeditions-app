This application presenting the expeditions of Dutch geophysicist and geodesist Felix Andries Vening Meinesz (1887-1966) was originally published in 2014 as part of [Expeditie Wikipedia](https://expeditiewikipedia.nl/). The original application has been rebuilt from scratch, and updated with new content.

Texts by [Bart Root](https://www.tudelft.nl/staff/b.c.root/) (Aerospace Engineering, TU Delft) and [Rozemarijn Vlijm](https://www.linkedin.com/in/rozemarijn-vlijm-8b1426128/). Development by [Jules Schoonman](https://www.tudelft.nl/staff/j.a.schoonman/) (Academic Heritage, History and Art, TU Delft Library).

For more information:

- [Stichting Academisch Erfgoed](https://www.academischerfgoed.nl/projecten/de-grote-wikipedia-expeditie/)
- [Wikipedia](https://nl.wikipedia.org/wiki/Wikipedia:GLAM/Expedities)

This application makes use of an open source template for creating narrative maps using [Allmaps](https://allmaps.org/). View the [source code on GitHub](https://github.com/tu-delft-heritage/gravity-expeditions-app) for more information.
